# Lernzentrale · KVF 2. Ausbildungsjahr

Interaktive Übungsmodule zu den Skripten der Lernsituationen (BbS IV „Friedrich List“, Halle). Je Lernsituation ein Modul als einzelne HTML-Datei.

**Live:** https://friedrichlist.github.io/Lernzentrale_2AJ_KVF/

Der Lernstand bleibt im Browser des jeweiligen Geräts. Kein Backend, keine Anmeldung, keine Datenübertragung.

| Datei | Zweck |
|---|---|
| `index.html` | Übersicht der Module |
| `KVF_LF06_LS06.1_Lernzentrale.html` | LF 6 · LS 06.1 „Kfz versichern – die Kundenakte Brehmer“ (TE 1–5) |
| `datenschutz.html` | Datenschutzhinweis |

## Neue Fassung einspielen

Die Module werden im OneDrive unter `KVF/Interaktive Lernzentrale` gebaut (`Werkzeug/bau_lz.py`, Daten in `Daten/`). Hier wird nur die fertige
Datei aus `Module/` hochgeladen – nie `Daten/`, `Werkzeug/` oder `Berichte/`. Nach dem Hochladen dauert es ein bis zwei Minuten, bis GitHub Pages
die neue Fassung ausliefert.
